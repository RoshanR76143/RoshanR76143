### 01 / VITees
#### AI Smart Classroom Attendance & Proxy Detection System

An intelligent classroom attendance and presence verification platform designed to improve attendance monitoring and identify potential proxy attendance using computer vision.

**Key Features**

- Facial detection and recognition for student identification.
- Automated classroom attendance verification.
- Mobile phone camera integration for classroom monitoring.
- Mobile camera-based door monitoring and student entry/exit detection.
- Presence verification to help identify proxy attendance.

**Technology Stack**

`Python` `FastAPI` `OpenCV` `InsightFace` `Supabase` `React` `TypeScript`
